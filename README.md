# 🔥 Feuerwehrquiz - Löschmittel und Löschverfahren

## Über die App

Eine innovative **Android-Quiz-App** zur spielerischen Schulung von Feuerwehr-Grundlagen. Entwickelt mit **Unity** als Abschlussprojekt für "Immersive Welten".

### 🎯 Features

- **5 realistische 3D-Brandszenarien** basierend auf den offiziellen Brandklassen (A-F)
- **15 praxisnahe Fragen** zu Löschmitteln und Löschverfahren
- **Interaktive 3D-Umgebung** mit Unity Assets
- **Rangliste** für Wettkampf-Atmosphäre
- **Offline-Funktionalität** mit lokaler Datenspeicherung

### 🎮 Spielablauf

1. **Namenseingabe** - Dein Name wird für die Rangliste gespeichert
2. **Quiz starten** - 15 Fragen zu 5 verschiedenen Brandszenarien
3. **3D-Szenarien erkunden** - Fragen ein-/ausblenden für bessere Sicht
4. **Ergebnisse analysieren** - Detaillierte Auswertung mit korrekten Antworten
5. **Rangliste checken** - Vergleiche dich mit anderen Spielern

## 📱 Download & Installation

### Voraussetzungen
- Android-Gerät (Version 7.0 oder höher)
- Mindestens 200 MB freier Speicherplatz

### Installation
1. **APK herunterladen** von [Repository/Download-Link]
2. **Unbekannte Quellen aktivieren** in den Android-Einstellungen
3. **APK-Datei öffnen** und Installation bestätigen
4. **App starten** und ersten Quiz-Durchgang absolvieren
